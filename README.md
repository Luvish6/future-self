# Future Self

A free, mobile-first, psychology-informed personal growth PWA: goals, future-self reflection, visualization, affirmations, habits, journaling, and guided night audio.

> A personal-development tool, not medical, financial, or mental-health treatment. No guaranteed outcomes.

**Stack:** React + TypeScript + Vite + Tailwind · Supabase (Auth, Postgres + RLS, Storage) · Cloudflare Pages · PWA.

**Status:** Phase 0 (spec + setup). See [docs/PROJECT_STATE.md](docs/PROJECT_STATE.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Development
App scaffold arrives in Phase 1. Then: `npm install`, `npm run dev`, `npm test`, `npm run typecheck`.
Copy `.env.example` to `.env.local` and fill in Supabase values (Phase 2).
